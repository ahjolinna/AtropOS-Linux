# AtropOS wallpapers

Seven still wallpapers and one silent video.

The stills install as Plasma image wallpaper packages under
`/usr/share/wallpapers/atropos-01` through `atropos-07`. The global theme
selects `atropos-02`.

The video installs as `/usr/share/atropos/wallpaper-animated.webm`. It is
not an image wallpaper. The wallpaper type `org.atropos.video` loops it
with Qt Multimedia. `qt6-multimedia` and `qt6-multimedia-imports` are
required. Choosing that type in the wallpaper dialog plays the packaged
file. The path can be changed there.

The artwork is the packager's collection (`LicenseRef-Proprietary`). The
plugin source is GPL-2.0-or-later.
